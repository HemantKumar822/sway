# Decision 0004 - Name locked: Medley

**Date:** 2026-08-23
**Decided by:** Owner (Hemant), direct choice
**Supersedes:** provisional name "Vitro" from `planning-artifacts/prd.md`; glass-centric naming direction in earlier drafts

## Decision

The product and app are named **Medley**.

- Rationale (owner): simple, catchy, unmistakably musical. A medley = songs flowing seamlessly into one another - the literal product promise of smooth playback and fluid transitions.
- Tagline candidate: "Your music, in flow."
- Rejected alternatives: Vitro/Prisma/Lumen (glass-themed, owner rejected glass-first identity), classical terms Meend/Dulcet/Cantabile/Anahata/Sotto (rejected as not simple/catchy). Study trail: `docs/research/naming-study.md`.

## Consequences

- Application label: Medley. Working package id until release check: `com.medley.music`.
- PRD patched accordingly (title, vision, glossary Artwork Surface term replaces Glass Surface).
- REMAINING before public release: trademark + Play Store collision verification for "Medley" in the music-app category.
